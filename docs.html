The AI can act on the secret, without learning the secret.

This document covers everything your team needs to build with CodeAstra. Every section is about doing something — protecting data, wrapping agents, building RAG pipelines, training models. Every code example is verified against the actual SDK (sdk/codeastra/client.py v2.1.0).

Layer 1 — BlindAgent
Wrap any AI agent. It becomes blind to sensitive data automatically. Works with LangChain, CrewAI, Claude, OpenAI, or anything with .run() / .invoke().
Layer 2 — ThinkingTokens
Real value goes to vault. Facts stay outside. Agent queries facts in natural language. Gets token IDs back — never real values. 50,000 records, zero exposure.
Layer 3 — Thinking Executor
Agent sends token IDs. Executor resolves real values, fires integrations, wipes. Agent gets success/fail. Real values exist for milliseconds.
User data → Codeastra vault → tokens
Agent sees tokens only — never real values
Executor resolves tokens → fires integrations
Real values wiped immediately after action
Agent receives result — never saw anything real

02 Make Any Data Blind

Before any AI agent, RAG pipeline, or fine-tuning job touches your data, Astra replaces real values with vault tokens. The AI sees tokens. Real values stay in the vault.

Protect free text

safe = client.protect_text("Call James at james@goldman.com SSN 234-56-7890")
# → "Call James at [CVT:EMAIL:A1B2] [CVT:SSN:C3D4]"

# Full response with entity list
full = client.protect_text_full("Call James at james@goldman.com SSN 234-56-7890")
# → { "protected_text": "...", "entities": [...], "tokens_created": 2 }python

Tokenize structured records

tokens = client.tokenize({
    "name":  "John Smith",
    "ssn":   "123-45-6789",
    "email": "john@hospital.org",
    "age":   34,      # not sensitive — stays as-is
    "ward":  "ICU"    # not sensitive — stays as-is
})
# → {
#     "name":  "[CVT:NAME:A1B2]",
#     "ssn":   "[CVT:SSN:C3D4]",
#     "email": "[CVT:EMAIL:E5F6]",
#     "age":   34,
#     "ward":  "ICU"
#   }python

Resolve a token (executor only)

result = client.vault_resolve("[CVT:EMAIL:A1B2]")
# → { "authorized": true, "real_value": "john@hospital.org" }

results = client.vault_resolve_batch(["[CVT:EMAIL:A1B2]", "[CVT:SSN:C3D4]"])python
Resolution is gated. Only your executor layer can call this endpoint. Your AI agent cannot.

Wipe real values permanently

client.vault_wipe_token("[CVT:EMAIL:A1B2]")      # wipe single token
client.vault_wipe_cohort("hospital_2024")         # wipe entire cohort
client.vault_wipe_session(session_id)              # wipe entire session

# Deletion proof for GDPR auditors
proof = client.vault_wipe_proof()
# → {
#     "proven": true,
#     "wiped_at": "2025-05-28T14:22:11Z",
#     "real_value_exists": false,
#     "compliance_statement": "Real value permanently deleted. Cannot be recovered."
#   }python

05 ThinkingTokens — AI That Acts Without Seeing

ThinkingTokens let you run an AI over thousands of sensitive records without the AI ever reading them. Real values go into the vault. The AI works with facts and signals only.

1. Mint a ThinkingToken per record. Real value → vault. Facts → visible to AI.
2. AI queries facts in natural language. Gets back token IDs, never real values.
3. Executor takes token IDs, resolves real values, fires actions, wipes.

Mint a ThinkingToken

token = client.think_mint(
    real_value = "Maria Santos | SSN:234-56-7890 | Phone:404-555-0192",
    data_type  = "patient",
    facts      = {
        "age":               30,
        "risk":              "high",
        "diagnosis":         "diabetes",
        "last_contact_days": 45,
        "insurance":         "medicaid",
    },
    cohort_id         = "hospital_2024",
    signal_conditions = [
        {"if": "risk == 'high'",         "signal": "needs_callback_today"},
        {"if": "last_contact_days > 30", "signal": "overdue_contact"},
    ],
    ttl_hours = 720,
)
# → { "token_id": "tht_PATI_c7dd388e4f" }
# Maria Santos is in the vault. The AI never sees her name or SSN.python

Mint in bulk

results = client.think_mint_batch([
    {
        "real_value": "John Doe | DOB: 1981-04-12",
        "data_type":  "patient",
        "facts":      {"age": 43, "risk": "low"},
        "cohort_id":  "hospital_2024",
    },
    # ... more records
])
# → { "tokens": ["tht_PATI_abc", ...], "minted": 100 }python

Query in natural language

results = client.think_query(
    query     = "high risk patients not contacted in 30 days",
    cohort_id = "hospital_2024",
    top_k     = 200,
)
# → {
#     "matched_tokens":          ["tht_PATI_c7dd388e4f", ...],
#     "match_count":             201,
#     "real_data_seen_by_agent": 0
#   }python

Get proactive signals

signals = client.think_signal("hospital_2024")
# → {
#     "signals": [
#       { "token_id": "tht_PATI_c7dd388e4f", "signal": "needs_callback_today" },
#       { "token_id": "tht_PATI_d8ee499f50", "signal": "overdue_contact" }
#     ],
#     "real_data_seen": 0
#   }python

Read token memory

memory = client.think_memory("tht_PATI_c7dd388e4f")
# → {
#     "events": [
#       { "type": "query_match",    "query": "high risk...",       "at": "..." },
#       { "type": "signal_fired",   "signal": "needs_callback_today", "at": "..." },

Revoke a token

# Real value wiped. Token stops resolving. Memory purged.python

06 Thinking Executor — Fire Integrations Without Exposing Data

The executor is the only layer that resolves tokens into real values. It resolves, fires the action, wipes. Your AI agent only ever sees the result: success or failure.

Register integrations

client.executor_register_integration("vapi", {
    "api_key":         "vapi_live_xxx",
    "phone_number_id": "pn_xxx",
    "assistant_id":    "asst_xxx"
})
client.executor_register_integration("twilio", {
    "account_sid": "AC...",
    "auth_token":  "...",
    "from_number": "+15551234567"
})
client.executor_register_integration("sendgrid", {
    "api_key":    "SG.xxx",
    "from_email": "noreply@yourcompany.com"
})
client.executor_register_integration("stripe", {"api_key": "sk_live_..."})
client.executor_register_integration("webhook", {
    "url":     "https://your-server.com/hook",
    "method":  "POST",
    "headers": {"Authorization": "Bearer xxx"}
})python

All supported: Vapi, Twilio, SendGrid, Stripe, Plaid, Epic EHR, DocuSign, Salesforce, HubSpot, Zendesk, any HTTPS webhook.

Define decision rules

client.executor_register_rule(
    name="call_high_risk",   integration="vapi",     action_type="call",
    conditions=[{"field": "risk", "op": "eq", "value": "high"}],   priority=10,
)
client.executor_register_rule(
    name="sms_medium",       integration="twilio",   action_type="sms",
    conditions=[{"field": "risk", "op": "eq", "value": "medium"}], priority=5,
)
client.executor_register_rule(
    name="email_overdue",    integration="sendgrid", action_type="email",
    conditions=[{"field": "last_contact_days", "op": "gt", "value": 30}], priority=1,
)python

Run on a cohort

07 Blind RAG — Documents Your AI Can Reason Over But Never Read

Documents are tokenized before they are stored. The LLM queries a token index. It never reads the raw documents.

Sensitive documents → tokenize on ingest → token index stored
LLM query → search token index → retrieve relevant token chunks
LLM receives token chunks → generates answer — real values never appear

Ingest a document

result = client.rag_ingest(
    content        = {
        "text":       "Patient John Smith, SSN 123-45-6789, diagnosed with...",
        "patient_id": "MRN-8847",
        "year":       2024,
    },
    doc_type       = "patient_record",
    title          = "Patient Intake 2024",
    source         = "EHR",
    classification = "phi",
)
# → { "document_id": "doc_xxx", "chunks": 12, "real_content_stored": false }python

Search

results = client.rag_search(
    query     = "treatments for diabetic patients over 60",
    doc_type  = "patient_record",
    top_k     = 5,
    min_score = 0.3,
)
# → {
#     "results": [
#       { "doc_id": "doc_xxx", "chunk": "Treatment for [CVT:CONDITION:X1Y2]...", "score": 0.94 }
#     ],
#     "real_content_seen_by_llm": false
#   }python

Ingest a batch / delete a document

results = client.rag_ingest_batch([
    {"content": {"text": "Record 001...", "patient_id": "MRN-001"}, "doc_type": "patient_record"},
    {"content": {"text": "Record 002...", "patient_id": "MRN-002"}, "doc_type": "patient_record"},
])

client.rag_delete("doc_xxx")   # all chunks and token mappings — permanently deletedpython
Blind RAG search returns token-indexed chunks. Pass them as context to client.invoke() for final answer generation. Real values stay in the vault throughout.

10 Smart Tokens — Policy-Gated Access

Smart Tokens add conditional logic on top of vault tokens. Define the exact conditions under which a token can be revealed. If conditions aren't met, the token is policy-blocked — not just unauthenticated.

smart = client.smart_tokenize(
    real_value      = "IBAN: GB29NWBK60161331926819",
    data_type       = "bank_account",
    allowed_actions = ["payment_initiation"],
    allowed_targets = ["https://payments.internal.com"],
    max_uses        = 1,      # single-use — burned after first reveal
    ttl_seconds     = 86400,
    semantic_label  = "payment_iban",
)
# → { "token_id": "tok_BANK_abc123", "max_uses": 1 }

result = client.smart_token_execute(
    token_id    = "tok_BANK_abc123",
    action_type = "payment_initiation",
    target_url  = "https://payments.internal.com",
    field_name  = "destination_iban",
)
# → { "real_value": "GB29NWBK60161331926819", "uses_remaining": 0, "burned": true }
# If action not in allowed_actions: { "error": "policy_blocked" }

client.smart_token_revoke("tok_BANK_abc123")

audit = client.smart_token_audit("tok_BANK_abc123")
# → [{ "type": "minted" }, { "type": "executed" }, { "type": "burned" }]python

11 BYOK — Bring Your Own Key & Crypto-Delete

Integrate your own KMS. Your vault data is encrypted with your key. Astra never holds the plaintext. Deleting your key makes all vault data permanently irrecoverable instantly.

# AWS KMS
client.byok_configure(provider="aws_kms",  key_arn="arn:aws:kms:us-east-1:123456789:key/mrk-abc123")

# GCP KMS
client.byok_configure(provider="gcp_kms",  key_id="projects/my-proj/locations/global/keyRings/my-ring/cryptoKeys/my-key")

# HashiCorp Vault
client.byok_configure(provider="hashicorp_vault", vault_url="https://vault.yourcompany.com", key_path="transit/keys/codeastra")

client.byok_test()    # verify key is accessible
client.byok_rotate()  # re-encrypt all tokens with new key version — no downtime

# GDPR Article 17 — crypto-delete
result = client.byok_cryptographic_delete()
# → { "deleted": true, "tokens_made_irrecoverable": 48291 }
# Key deleted. Every token encrypted with it is permanently unreadable.python
GDPR Article 17 at the cryptographic level: You do not need to find and delete individual records. Delete the key — everything encrypted with it becomes irrecoverable in milliseconds.

12 FHE — Compute on Encrypted Data

Fully Homomorphic Encryption lets you run computations on data without decrypting it. The server never sees plaintext. Only you can decrypt the result.

pip install codeastra[fhe]   # required for local encrypt/decryptbash

One-shot: encrypt → compute → decrypt

# Server sees only ciphertext — never the salary value
result = client.fhe_full_compute(
    value     = 95000.0,
    operation = "percentage_of",
    params    = {"rate": 7.5},
)
print(result)  # → 7125.0  — server never saw 95000python

Manual flow

session    = client.fhe_setup(preset="standard")
ciphertext = client.fhe_encrypt(95000.0, session)

he_result  = client.fhe_compute(
    operation          = "percentage_of",
    encrypted_inputs   = {"value": ciphertext},
    plaintext_params   = {"rate": 7.5},
    key_id             = session.key_id,
    public_context_b64 = session.public_context_b64,
)

plaintext = client.fhe_decrypt(he_result, session)
print(plaintext)  # → 7125.0python

SIMD batch

session    = client.fhe_setup()
ciphertext = client.fhe_encrypt_batch([95000.0, 72000.0, 110000.0], session)
he_result  = client.fhe_compute_batch(
    operation="percentage_of", encrypted_inputs={"value": ciphertext},
    plaintext_params={"rate": 7.5}, key_id=session.key_id,
    public_context_b64=session.public_context_b64,
)
results = client.fhe_decrypt_batch(he_result, session)
print(results)  # → [7125.0, 5400.0, 8250.0]python

Supported operations: percentage_of · add_constant · multiply_constant · subtract_constant · compare_gt · compare_lt
